# The ideas behind

*Five big ideas that explain almost every puzzle on this site*

Puzzles look like a jumble of separate tricks: a parity argument here, a doubling there, a clever strategy for a game
of stones. But the same few ideas come back again and again. Learn them, and a new puzzle stops being a mystery and
becomes a question you know how to ask. Each page below explains one idea, shows where it appears in the puzzles, and
points to where it leads in real mathematics and computing.
